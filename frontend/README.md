# Virtual Trading Platform - Frontend

## Setup

```bash
cd frontend
npm install
```

## Environment Variables

Create `.env.local`:

```env
NEXT_PUBLIC_API_URL=http://localhost:5000/api
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Build for Production

```bash
npm run build
npm start
```

## Pages

- `/` - Home page
- `/login` - User login
- `/register` - User registration
- `/market` - Market data
- `/trade` - Trading interface (coming soon)
- `/portfolio` - Portfolio management (coming soon)
- `/admin` - Admin dashboard (coming soon)
